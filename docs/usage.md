# 使い方

## タブレット

1. `AndroidTabletCast-android.apk` をインストールする。
2. アプリで名前を確認し、「配信を開始」を押す。
3. 画面収録を許可する。
4. 表示された PIN と IP を控える。ポートは 39721。
5. タップや文字を返すなら、ユーザー補助で Tablet Cast をオンにする。
6. より直接的な操作が欲しいときは Shizuku を起動し、アプリから許可する。

配信を止めると PIN は無効になる。次に始めると新しい PIN になる。

## Windows 11

1. zip を展開し、`AndroidTabletCast.exe` を起動する。
2. ファイアウォールではプライベートネットワークを許可する。
3. 一覧のタブレットを選ぶ。出ないときは IP を直接入れる。
4. PIN を入力して接続する。
5. 右クリックは戻る、中クリックはホーム、ホイールはスクロール。
6. 画質は「高画質」「バランス」「低遅延」から切り替える。

FFmpeg の DLL が無いと起動直後に不足が表示される。開発時は `windows/tools/fetch-ffmpeg.ps1` を実行してからビルドする。

## 信頼モード

1. 一度 PIN で接続する。
2. Windows で「この PC を信頼させる」を押す。
3. タブレットに出た PC 名を確認して許可する。
4. タブレットで「信頼するデバイスは PIN 不要」をオンにする。
5. 次からは PIN を空にして接続する。

スイッチをオフにすると、登録が残っていても PIN が要る。タブレットの一覧で取り消すと、その PC は未信頼に戻る。Windows の「このタブレットの信頼を消す」は、PC 側に保存したトークンだけを消す。

トークンを渡す瞬間は同じ Wi-Fi 上を平文で通る。信用できないネットワークではスイッチをオフのままにする。

## つながらないとき

- ゲスト Wi-Fi や AP アイソレーションは端末同士の通信を止める。
- Windows ファイアウォールが UDP 39720 を止めていると一覧に出ない。IP 直入力は TCP 39721 だけで足りる。
- 映像が固まったら一度切断して、同じ PIN でつなぎ直す。配信を止めない限り PIN は変わらない。
