Android Tablet Cast

Android タブレットの画面を、同じ Wi-Fi の Windows 11 へ高画質・低遅延で映す。操作は Windows からタブレットへ返す。

入れるもの

  • タブレットには APK
  • Windows 11 には展開した exe と FFmpeg の DLL

つなぎ方

  1. タブレットで配信を開始し、PIN を確認する。
  2. Windows で同じ Wi-Fi 上のタブレットを選ぶ。見つからなければ IP とポート 39721 を入れる。
  3. PIN を入力して接続する。

信頼するデバイス

既定は毎回 PIN。タブレットで「信頼するデバイスは PIN 不要」をオンにし、PIN 接続中に Windows から信頼を依頼してタブレットで許可すると、その PC は次回から PIN なしでつながる。未登録の PC は、スイッチがオンでも PIN が必要。

操作

ユーザー補助でタップ、ドラッグ、文字入力、戻る、ホームを返す。Shizuku を許可すると、より直接的な入力になる。右クリックは戻る、中クリックはホーム。

詳しくは usage.md、architecture.md、protocol.md。
