Android Tablet Cast

Android タブレットの画面を、同じ Wi-Fi の Windows 11 へ高画質・低遅延で映す。操作は Windows からタブレットへ返す。

入れるもの

  • タブレットには APK
  • Windows 11 には展開した exe と FFmpeg の DLL

つなぎ方

  1. タブレットで配信を開始し、PIN を確認する。
  2. Windows で同じ Wi-Fi 上のタブレットを選ぶ。同じ端末は 1 件だけ出る。見つからなければ IP とポート 39721 を入れる。
  3. PIN を入力して接続する。

信頼するデバイス

既定は毎回 PIN。タブレットで「信頼するデバイスは PIN 不要」をオンにし、PIN 接続中に Windows から信頼を依頼してタブレットで許可すると、その PC は次回から PIN なしでつながる。PIN 欄に前回の値が残っていても信頼を先に使う。未登録の PC は、スイッチがオンでも PIN が必要。

操作

ユーザー補助でタップ、ドラッグ、文字入力、戻る、ホームを返す。Shizuku を許可すると、より直接的な入力になる。右クリックは戻る、中クリックはホーム。

最高画質と高画質は長辺 3840 までで、3K の画面も縮小せずに送ります。最高画質は 120Mbps です。HEVC のハードウェアエンコーダがあるタブレットは H.265、無い場合は H.264 です。「他のアプリの上に表示」を許可すると、ほかのアプリを開いても収録が止まりにくくなります。

OBS

Windows の「OBS 用ウィンドウ」は映像だけの別ウィンドウです。OBS ではウィンドウキャプチャの「タブレット映像（OBS）」を選びます。このウィンドウへの操作はタブレットへ送りません。

詳しくは usage.md、architecture.md、protocol.md。
