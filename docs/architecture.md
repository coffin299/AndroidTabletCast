# アーキテクチャ

タブレットが画面を送り、Windows 11 が表示する。操作は Windows からタブレットへ戻す。中継サーバはなく、同一 LAN の TCP だけを使う。

## 映像と音声

Android は `MediaProjection` の仮想ディスプレイを `MediaCodec` の H.264 エンコーダへ渡す。仮想ディスプレイは、画面収録を許可した直後（アプリが前面にあるうち）に作る。接続時には作り直さない。同じ画質の再指定でも作り直さない。B フレームは使わず、機種が受け付ける範囲で CBR とリアルタイム優先を指定する。約 2 秒ごとに IDR を出し、PC からの要求でも即時に IDR を出す。接続が通ったときは、直前の SPS/PPS と IDR を送り直す。

音声は Android 10 以降の再生音キャプチャを AAC-LC にする。マイクは使わない。取れないアプリや端末では映像だけ続ける。

Windows は FFmpeg 7.1 の LGPL 共有ライブラリで H.264 と AAC をデコードする。DLL は実行ファイルの横に置き、リポジトリには入れない。映像は待たせず、描画が追いつかないフレームは捨てる。目標は同一 Wi-Fi で 1〜2 フレームにネットワーク往復を足した程度。

## 探索

タブレットは UDP ブロードキャストと mDNS（`_atcast._tcp`）を出す。Windows はその両方を聞き、ダメなときは表示された IP を直接入れる。同時に映す PC は 1 台。

## 認証と信頼

配信を始めるたびに 6 桁の PIN を作る。既定では毎回 PIN が要る。

「信頼するデバイスは PIN 不要」はタブレット側のスイッチで、既定はオフ。オンのときだけ、登録済み PC が PIN を省略できる。未登録はオンでも PIN が要る。オフに戻すと、登録が残っていても全員 PIN に戻る。

信頼の登録は、PIN でつながったあとに Windows から依頼し、タブレットが PC 名を表示して許可したときだけ行う。トークンは PC が保存し、タブレットは `SHA-256(token)` だけを保存して HMAC の検証に使う。取り消すと、その PC は次回から PIN に戻る。

## 操作の返し

通常の APK だけでは他アプリへ入力イベントを注入できない。ユーザー補助ではタップ、ドラッグ、スクロール、フォーカス中の文字入力、戻る、ホームを行う。ジェスチャはシステムがまとめて実行するため、映像より遅れる。

Shizuku が許可されているときは、shell 権限のプロセスから `InputManager.injectInputEvent` を呼ぶ。ホバー、キー、タッチの遅れが小さくなる。Shizuku が無くても映像と基本操作は動く。

右クリックは Back、中クリックは Home。Esc はフルスクリーン中は解除、それ以外は Back。

Windows は操作パネル付きの本体ウィンドウとは別に、映像だけの「タブレット映像（OBS）」ウィンドウを開ける。OBS のウィンドウキャプチャ向けで、そのウィンドウへのクリックはタブレットへ送らない。

## リリース

GitHub Actions の Release workflow は手入力のタグで動く。形式は `v1.2.3` または `v1.2.3-rc.1`。既存タグは上書きしない。Android APK と Windows の zip を同じ Release に載せる。

署名 Secrets が無い APK は debug 署名なので、更新時はアンインストールが必要になる。
